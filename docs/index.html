About

Hi, I’m Walter Teitelbaum, but I go by Walt. I’m an automation and mechatronics engineer in Seattle, WA. My work spans robotics, motion control, Python software, and manufacturing test systems.

I enjoy building useful things, learning from the people around me, and helping teams do good work together. I grew up in the East Bay.

This site is a small home for projects, notes, and the occasional write-up. You can read my resume, download a print version, or browse my posts if you’d like to see what I’ve been working on.

October 2026

  • Testing a Thermal Fluid Loop with Simulation and Embedded Control. A Python simulation, a shared C controller, and a browser tool for exploring how a fluid loop responds to faults.
  • RFQFuzz: Regression Tests for Drawing Reviewers. Compare reviewer behavior on controlled CAD and drawing packages, with evidence for each changed finding.
  • FixtureForge: Checking Tool Access in CAD. Inspect whether a simplified tool can follow a declared path through a fixture or small assembly.

  • AbyssBench: Checking Controller Timing. Replay controller events and check whether the recorded response satisfies an explicit timing contract.
